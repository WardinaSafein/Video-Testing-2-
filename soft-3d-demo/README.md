# Soft 3D dachshund (Blender, built from code)

A 4-second seamless loop in a "soft 3D" / clay-toy style: rounded blob shapes,
soft studio lighting, a curved backdrop and shallow depth of field.
Everything in the scene is generated by `build_scene.py`. No models are hand-modelled.

## What's in the scene
- **Dog body and head** are metaballs, so the parts blend into one smooth "clay" shape.
- **Face parts, ears and collar** are placed by ray-casting onto the real surface,
  so they stay attached when the shape changes.
- **Animation:** breathing, head tilt, floppy ears (with lag), wagging tail,
  swinging tag, blinks, nose sniffs, and a ball bouncing with squash-and-stretch.
- **Render:** Cycles with the OpenImageDenoise denoiser and the AgX colour transform
  (Punchy look). Output is 864×1080, upscaled to 1080×1350 (Instagram 4:5) at 24fps.

## Run it
The official `bpy` module is required, because Ubuntu's `blender` package has no denoiser:

```bash
uv venv -p python3.13 bpyenv && VIRTUAL_ENV=bpyenv uv pip install bpy
bpyenv/bin/python build_scene.py            # writes soft3d_dog.blend (add "preview" for a quick low-res version)
bpyenv/bin/python render.py soft3d_dog.blend frames/f_ 1 96
ffmpeg -framerate 24 -i frames/f_%04d.png -vf scale=1080:1350:flags=lanczos \
       -c:v libx264 -pix_fmt yuv420p -crf 16 soft3d-dachshund.mp4
```

On 4 CPU cores a frame takes about 25–55 seconds, depending on resolution.
A GPU would make this 10–50× faster.

## Easy things to change (top of `build_scene.py`)
- Colours: the `M = dict(...)` palette
- Length and frame rate: `FPS, SECONDS`
- Camera: `cam.location`, `cam.data.lens`, `target.location`
- Motion amounts: the `for f in range(...)` animation loop
